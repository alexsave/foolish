# Foolish for iOS

Native SwiftUI port of foolish.cards — see [`docs/IOS_APP_DESIGN.md`](../docs/IOS_APP_DESIGN.md)
for the full design and build plan. This directory is the Xcode project; the
game engine lives in [`../cnitro`](../cnitro) (C, shared with the web/wasm build)
and is linked as a static `xcframework`.

## Bootstrap (from a clean checkout)

You need a Mac with **Xcode 16+** and two Homebrew tools:

```bash
brew install xcodegen        # generates the .xcodeproj from project.yml
# (SnapshotTesting is pulled automatically as a Swift package)
```

Then, in order:

```bash
# 1. Build the C engine as an xcframework (device + simulator slices).
cd cnitro && make ios-lib          # → ios/vendor/Foolish.xcframework

# 2. Generate the Xcode project from project.yml.
cd ../ios && xcodegen generate     # → Foolish.xcodeproj

# 3. Open it, or build/test from the shell.
open Foolish.xcodeproj
```

`ios/vendor/Foolish.xcframework` and `ios/Foolish.xcodeproj` are **build
artifacts** — both are git-ignored and regenerated by steps 1–2. Never hand-edit
either; change `project.yml` (project) or `cnitro/ios/*` (engine) instead.

## Build & test from the shell

```bash
cd ios
xcodebuild -project Foolish.xcodeproj -scheme Foolish \
  -destination 'platform=iOS Simulator,name=iPhone 16' build
xcodebuild -project Foolish.xcodeproj -scheme Foolish \
  -destination 'platform=iOS Simulator,name=iPhone 16' test
```

Simulator builds need **no code signing** (the project ships with signing off).
Device / TestFlight signing is set up in Milestone F.

## Verifying the engine without a Mac

The C bridge is portable; you can prove it on Linux/CI:

```bash
cd cnitro
make ios-smoke      # drives a full 4-player game through the Swift-facing API
make ios-goldens    # regenerates ios/Fixtures/goldens.json
```

`make ios-smoke` is the M-A keystone check that runs anywhere clang does. The
Swift `EngineGoldenTests` then assert the built `libfoolish.a` reproduces
`goldens.json` byte-for-byte.

## Layout

```
ios/
├─ project.yml            XcodeGen spec (the project's source of truth)
├─ FoolishApp/            app target: @main, routing, Home/Table/Win, Gallery (DEBUG)
├─ FoolishKit/            shared framework
│   ├─ Engine/            Swift bridge over libfoolish (EngineC, Models, LocalGame)
│   ├─ DesignSystem/      tokens, haptics, FCard/FHandFan/FButton/…, fern card back
│   ├─ Boards/            table rendering (TableView, battle grid, seat badge, …)
│   └─ Net/               online protocol (Milestone D — scaffolding only in v1)
├─ Entitlements/          §10 billing-ready seam (FreeEntitlements only in v1)
├─ FoolishTests/          golden, codec, and snapshot tests
├─ Fixtures/              goldens.json (generated by `make ios-goldens`)
└─ vendor/                Foolish.xcframework (generated by `make ios-lib`)
```
