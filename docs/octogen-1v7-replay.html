How to read the panels

  • Monte‑Carlo candidates. Away from the endgame octogen samples many possible worlds (deals of the hidden cards) and rolls each candidate move out to the end; the bar is its average finish position (1 = eliminated first = win, higher = worse). Lower is better. The chosen move is outlined; the best‑scoring move is green.
  • Trump‑keep tax. The weak rollout policy undervalues holding trumps while the deck is alive, so a low‑trump lead scores within noise of a junk lead and the raw Monte‑Carlo argmin would pick it ~half the time. octogen adds a small tax (trump‑keep) to the score of any move that leads a trump while the deck is alive, tipping those near‑ties toward keeping the trump. Taxed rows show raw + tax = adjusted; the ranking and the green “best” use the adjusted score.
  • Exact endgame solver. Once the deck is empty the hidden pool is the opponent's hand (see “octogen known state”), so octogen solves the position exactly — each move is a proven win / loss / draw rather than a sampled average.
  • octogen known state. This is octogen's actual belief, dumped from the engine. It pins the cards it watched the opponent pick up (still in their hand) — it knows those exactly — and treats the rest as an unknown pool (the face‑down deck + the opponent's un‑pinned cards). pinned + pool = deck + opponent, always. Once the deck empties the pool is just the opponent's remaining cards, so pinned + pool = the opponent's entire hand — the public deduction the exact solver runs on. It also tracks suit‑cover voids and rank floors from the same public log.
  • “octogen agrees / would differ.” At each octogen turn the recorded move is compared to what this octogen build picks on the true state. Ties are common: several moves often score within Monte‑Carlo noise, so a “differ” is usually a near‑tie, not a blunder (each flagged panel shows both scores). octogen is deterministic — its world‑sampling seed is state_fnv over the ordered hands + deck — so a matched move is bit‑exact. A near‑tie can still “differ” because that seed also hashes the opponent’s hand order, and a human can rearrange their hand (a drag‑to‑reorder meta‑action that is not stored in the replay). When that happens the exact tie‑break can’t be recovered from the public replay — the move sets still match, only the noise‑level ordering differs.
