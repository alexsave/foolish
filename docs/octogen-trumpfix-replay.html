How to read the panels

  • Monte‑Carlo candidates. Away from the endgame octogen samples many possible worlds (deals of the hidden cards) and rolls each candidate move out to the end; the bar is its average finish position (1 = eliminated first = win, higher = worse). Lower is better. The chosen move is outlined; the best‑scoring move is green.
  • Exact endgame solver. Once the deck is empty the hidden pool is the opponent's hand (see “octogen known state”), so octogen solves the position exactly — each move is a proven win / loss / draw rather than a sampled average.
  • octogen known state. This is octogen's actual belief, dumped from the engine. It pins the cards it watched the opponent pick up (still in their hand) — it knows those exactly — and treats the rest as an unknown pool (the face‑down deck + the opponent's un‑pinned cards). pinned + pool = deck + opponent, always. Once the deck empties the pool is just the opponent's remaining cards, so pinned + pool = the opponent's entire hand — the public deduction the exact solver runs on. It also tracks suit‑cover voids and rank floors from the same public log.
  • “octogen agrees / would differ.” At each octogen turn the recorded move is compared to what this octogen build picks on the true state. Ties are common: several moves often score within Monte‑Carlo noise, so a “differ” is usually a near‑tie, not a blunder (each flagged panel shows both scores).
