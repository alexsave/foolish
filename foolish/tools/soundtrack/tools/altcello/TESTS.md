## Stage 2 (body, four strings, wav)

The coupling is one conservative leapfrog of the whole instrument.
The strings' bridge end value y[N] is the bridge displacement z = sum_k c_k q_k.
The force on the bridge is minus dV/dz of the discrete string potential (`string_bridge_force` with the end value included), the body modes use the state at time n like the strings do.
There is no solve and no lag, and the energy balance is exact (T8).

## Microphone proximity effect (room.c, mic study iteration 1)
Cardioid capsule pressure per arrival: p (0.5 + 0.5 cos(phi) (1 + c / (j w r))), r the path length of that arrival (the figure-8 half acts on the pressure gradient of a spherical wave, which carries the factor 1 + 1 / (j k r)).
Realised for the direct sound and every image arrival of order up to 6 (not the FDN tail, a diffuse field): each arrival adds an impulse of weight A 0.5 cos(phi) c / r (A the arrival's amplitude per band) to a second set of band buffers, integrated once by 1 / (j w + w0) with w0 = 2 pi 4 Hz (one first order IIR; the same filter for every arrival, each keeps its own r in the weight). The integrated part runs past the crossover without the crossfade. `--mic X,Y,Z` places the capsule in room coordinates aimed at the source, `--no-proximity` switches it off.
- T33 (test_room, t_proximity): direct sound alone (order 0, 400 m box so nothing else lands in the 0.5 s window, flat source directivity).
