# The Game Boy's tunes: the website's placeholders (OUT, GOOD, HAND_OFF,
# FINISH, FOOL) designed for the DMG, a motif a city for the win screen, and
# the fireworks. Read by tools/gen_tab.py into snd_tab.c. Plain text.
#
# Times count in 1/241 s (24 is about 100 ms); gen_tab.py converts them to
# the driver's ticks (60 a second), rounding the running time.
#
#   cue NAME PRIO              starts a cue (its takes follow)
#   take                       starts the cue's next take
#   ch N                       the channel the rows below are for (1 to 4)
#   p NOTE T VOL ENV DUTY [SWEEP]   a pulse note (CH1, CH2): VOL 0-15, ENV the
#                              envelope (-n falls one step every n/64 s, +n
#                              rises, 0 holds), DUTY 0-3 (12.5/25/50/75%),
#                              SWEEP CH1's NR10 in hex
#   g NOTE T                   a glide: the pitch only, no retrigger
#   w NOTE T LEVEL WAVE        a wave note (CH3): LEVEL 1 100%, 2 50%, 3 25%
#   n POLY T VOL ENV           a noise burst (CH4): POLY is NR43 in hex
#   r T                        a rest
# NOTE is like C5, F#4, Bb3 (A4 = 440 Hz).
