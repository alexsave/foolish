# The seed is set by poking sys_time (the one entropy source) just before the
# first press, so the deal does not depend on how long the ROM takes to start.
#
# A whole game I win, by a fixed input loop: try each card in turn (RIGHT, UP,
# UP to commit a target), nine times, then DOWN (take or done). Ends
# with Miami the fool, the win picture with the bot's name, then A: a rematch.
# The game is real time (the bot moves 30 frames after the board settles), so a
# change in how long the ROM takes to draw can change its course: if this ever
# loses, re-pick the seed (seeds 3, 4, 5, 8, 12 and 13 win today; 2 stopped winning when the art of 6ee55c5ef changed the draw times).
@99  poke _sys_time 03 00
@100 press A
# The loop runs past the end of the game on purpose: the end picture ignores
# LEFT, RIGHT, UP and DOWN, so the game's real-time pace cannot break the script.
repeat 30
repeat 9
+8   press RIGHT
+5   press UP
+5   press UP
endrepeat
+6   press DOWN
+30  press RIGHT
endrepeat

+0   expect _G+78 01
+0   expect _screen 02
+0   shot shots/80_win_screen.png 3
# A: a rematch, a new deal from the same stream
