# The seed is set by poking sys_time (the one entropy source) just before the
# first press, so the deal does not depend on how long the ROM takes to start.
# Every command at frame N acts after frame N ran (gbrun), so an expect and a
# press on the same frame see the press: steps leave a frame between them.
# The bot acts again 30 frames after the board last changed, so the steps of
# one bout fit inside that window.
#
# UP passes at once when the card can only pass: Miami leads the six of clubs
# (diamonds trump); my six of spades passes it on. Hand: 6s Js Ks 7h Jc 9d.
@99  poke _sys_time 06 00
@100 press A
+1   until _G+74 01
# the attack's cards land first (they fly for 12 frames)
+0   until _fly_n 00
+1   press RIGHT
+4   expect _cur 00
+0   shot shots/30_pass_only.png 3
+1   press UP
+5   expect _in_target 00
+0   expect _G+74 02
+0   expect _G+76 01
# a frame after the move's redraw (the attack's cues are still playing: the
# sound's tick takes about 1 ms of each frame while they do)
+1   shot shots/31_passed_at_once.png 3
