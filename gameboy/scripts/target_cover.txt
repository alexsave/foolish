# The seed is set by poking sys_time (the one entropy source) just before the
# first press, so the deal does not depend on how long the ROM takes to start.
# Every command at frame N acts after frame N ran (gbrun), so an expect and a
# press on the same frame see the press: steps leave a frame between them.
# The bot acts again 30 frames after the board last changed, so the steps of
# one bout fit inside that window.
#
# TARGET mode, cover: Miami opens with two eights (hearts, clubs); diamonds are
# trumps and my ten of diamonds beats either. Hand: 7s Kh 9c Tc Ac Td.
@99  poke _sys_time 01 00
@100 press A
+1   until _G+74 02
+0   shot shots/10_defend.png 3
# right then left: the cursor wraps from the first card to the last (the ten)
+1   press RIGHT
+4   press LEFT
+4   expect _cur 05
+1   press UP
+4   expect _in_target 01
+0   expect _tgt_n 02
+0   shot shots/11_target_cover_first.png 3
# right: the arrow moves to the other eight
+1   press RIGHT
+4   expect _tgt_i 01
# the redraw of a moved aim takes until about frame 6 (frame 4 shows the new
# arrow's sprites over the old path: README "Not done"), so the shot waits
+4   shot shots/12_target_cover_second.png 3
# down cancels back to the cards; up again aims at the first eight, up covers it
+1   press DOWN
+4   expect _in_target 00
+1   press UP
+4   expect _in_target 01
+1   press UP
+4   expect _in_target 00
+0   expect _G+56 1f ff
+0   shot shots/13_covered.png 3
