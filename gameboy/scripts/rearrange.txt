# The seed is set by poking sys_time (the one entropy source) just before the
# first press, so the deal does not depend on how long the ROM takes to start.
# Every command at frame N acts after frame N ran (gbrun), so an expect and a
# press on the same frame see the press: steps leave a frame between them.
#
# SELECT held + LEFT/RIGHT slides the cursor card through the hand (the
# website's Cmd+arrows); it never plays. Hand: Ts 9h Th 6d 7d Td.
@99  poke _sys_time 3a 00
@100 press A
+20  press RIGHT
+6   expect _disp 04 0c 0d 1b 1c 1f
+1   press SELECT 40
+8   press SELECT+RIGHT 2
+6   press SELECT+RIGHT 2
+6   expect _cur 02
+0   expect _disp 0c 0d 04 1b 1c 1f
+0   shot shots/60_rearrange_held.png 3
# UP while SELECT is held does nothing
+1   press SELECT+UP 2
+6   expect _G+74 00
# released: the order stays, and the cursor stays on the moved card
+20  expect _disp 0c 0d 04 1b 1c 1f
+0   expect _cur 02
+0   shot shots/61_rearranged.png 3
